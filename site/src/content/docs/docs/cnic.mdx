Checks the structure of a 13-digit Computerised National Identity Card number, and reads the two facts the number itself encodes: the province where it was first registered and the holder's gender. It also finds and masks CNICs in free text, for example before logging a chat message.

<CnicWidget client:visible />

:::caution[A format check, not identity verification]
A valid result means the number is well formed. It does not mean the CNIC exists or belongs to anyone. Only NADRA (Verisys) can verify an identity.
:::

## Reference

### validateCNIC()

```ts
function validateCNIC(cnic: string): boolean;
```

**Parameters.** `cnic`: 13 digits, plain or grouped 5-7-1 with hyphens, en dashes, spaces or dots. Urdu digits are accepted.

**Returns** `true` when the number has the right shape and starts with a province code from 1 to 8; otherwise `false`. It never throws.

**Caveats.** NADRA does not publish a check-digit algorithm, so the last digit is not verified. Separators are only accepted between the 5-7-1 groups.

**Related:** [`getCNICInfo()`](#getcnicinfo), the [CNIC checker](/tools/cnic/).

### getCNICInfo()

```ts
function getCNICInfo(cnic: string): CNICInfo | null;

interface CNICInfo {
  digits: string; // 13 digits
  formatted: string; // 35202-1234567-1
  province: string; // where the CNIC was first registered
  gender: 'male' | 'female';
}
```

**Parameters.** `cnic`: as for `validateCNIC()`.

**Returns** the decoded parts, or `null` when the CNIC is not valid.

**Caveats.** The province is where the CNIC was first registered, not necessarily where the holder lives now. Gender comes from the last digit: odd for male, even for female.

**Related:** [`validateCNIC()`](#validatecnic), [`formatCNICInput()`](/api/typescript/input/functions/formatcnicinput/) for as-you-type fields.

### findCNICs()

```ts
function findCNICs(text: string): CNICMatch[];

interface CNICMatch {
  raw: string; // as written, e.g. '35202 1234567-1'
  digits: string; // '3520212345671'
  formatted: string; // '35202-1234567-1'
  start: number; // offset of the first character
  end: number; // offset just after the last one
}
```

**Parameters.** `text`: any text, such as a chat message, a note or an uploaded document.

**Returns** every CNIC in the text, in order, or `[]`. A match is a run of exactly 13 digits starting with a province code (1-8), together or in any grouping joined by single separators: a space, a hyphen or dash, a dot or a slash (`3520212345671`, `35202-1234567-1`, `352 0212 3456 71`, `35202/1234567/1`). Inside a longer run of such groups, a CNIC written in 5-7-1 groups is still found (`0300-1234567 35202-1234567-1`). Digits may be ASCII, Urdu or Arabic-Indic, even mixed. It never throws.

**Caveats.**

- A match never starts or ends next to another digit, and a run of more than 13 digits is never cut into a CNIC except at 5-7-1 groups. Two separators in a row (`35202 - 1234567 - 1`) end a run.
- It is a pattern match, and since 2.7.1 a looser one: any 13 digits starting with 1-8, however they are grouped (an account, order or tracking number, or two shorter numbers written together), are found. Expect more false positives than with the 5-7-1 form alone; that is the price of catching CNICs as people really type them.
- It is looser than [`validateCNIC()`](#validatecnic), which stays strict and needs the same separator twice.
- Offsets are in UTF-16 code units in TypeScript, Dart and C#, and in characters (code points) in Python and PHP (use `mb_substr`), so slicing the text with them gives `raw` in each language.

### maskCNICs()

```ts
function maskCNICs(
  text: string,
  options?: {
    mask?: string; // replaces each digit; default 'X'
    replacement?: string; // replaces each whole CNIC instead
  },
): { text: string; count: number };
```

**Returns** the text with each digit of every CNIC found by [`findCNICs()`](#findcnics) replaced by `mask`, keeping the separators (`35202-1234567-1` becomes `XXXXX-XXXXXXX-X`), and how many CNICs were masked. With `replacement`, each whole CNIC, separators included, becomes that text instead (`{ replacement: '[CNIC removed]' }`); it takes precedence over `mask`. It never throws.

**Caveats.** Like `findCNICs()`, it also masks any other 13 digits that start with 1-8, however they are grouped.
