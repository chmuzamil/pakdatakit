`import { getDataInfo, listDataInfo } from 'pakdatakit/data-info'`

Every dataset has an entry in `data/manifest.json`, which CI checks against the data. Results calculated from dated data also carry a `source` (calculateSalaryTax, calculateSalesTax, calculateWithholding, zakatDeduction and others), so you can show or log which law, notification or table a figure came from.

## Reference

### getDataInfo()

```ts
function getDataInfo(id: string): DataInfo | null;
// { id, file, title, issuer, sourceUrl, sourceReference, sourceDate,
//   retrievedAt, effectiveFrom, effectiveTo, coverage, recordCount,
//   nextExpectedUpdate, updateCadence, notes }
```

**Returns** one dataset's entry. Dates are `YYYY-MM-DD`; a source that gives only a year or month keeps that (`2008`, `2021-02`), and an undated source has `sourceDate: null`.

### listDataInfo()

```ts
function listDataInfo(): DataInfo[];
```

**Returns** every dataset's entry, in id order.

### The `source` on results

```ts
interface DataSource {
  id: string; // the dataset
  effectiveFrom: string;
  effectiveTo: string | null;
  sourceReference: string; // the law, SRO, circular or notification
  sourceUrl: string;
}
```
