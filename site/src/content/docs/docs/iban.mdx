A Pakistani IBAN is 24 characters: `PK`, two check digits, a four-letter bank code and a 16-digit account number. These functions check the format and checksum and name the bank.

<IbanWidget client:visible />

:::caution[A valid IBAN is not a verified account]
The checksum catches typos. It does not confirm the account exists or who owns it; only the bank (or a payment through it) can.
:::

## Reference

### validateIBAN()

```ts
function validateIBAN(iban: string): boolean;
```

**Parameters.** `iban`: with or without spaces, any case.

**Returns** `true` when the IBAN is a Pakistani IBAN of the right length and its ISO 13616 mod-97 checksum is correct.

**Related:** [`getBankFromIBAN()`](#getbankfromiban), the [IBAN checker](/tools/iban/).

### getBankFromIBAN()

```ts
function getBankFromIBAN(iban: string): string | null;
```

**Returns** the bank's name for a valid IBAN, or `null` when the IBAN is invalid or the bank code is unknown.

### getBankInfo()

```ts
function getBankInfo(ibanOrCode: string): BankInfo | null;

interface BankInfo {
  code: string; // e.g. MEZN
  name: string;
  type: string; // 'commercial' | 'islamic' | 'microfinance' | 'digital' | 'emi' | ...
  active: boolean;
  mergedInto: string | null;
  aliasOf: string | null;
  status: 'active' | 'merged' | 'liquidated';
  website: string | null; // from SBP's lists, or the bank's own site
  websiteSbpListed: string | null; // SBP's value, where the bank moved domain
  swift: string | null; // 8-character BIC, only where SBP or the bank prints it
  swiftSource: {
    bicSource: 'sbp' | 'bank-site';
    printed: string;
    sourceUrl: string;
    page: number | null;
    checkedAt: string;
  } | null;
  swiftReason: string | null; // why swift is null
}
```

**SWIFT/BIC codes** are given only where SBP or the institution's own website prints them (16 codes for 15 banks), with where. Codes derived from Roshan Digital or branch codes are not used. 1LINK IMD codes are not included: there is no official public source.

**Parameters.** `ibanOrCode`: an IBAN or a four-letter bank code.

**Returns** the bank's details, including whether it still operates and what it merged into.

**Caveats.** Bank codes are checked against real IBANs and the State Bank of Pakistan's lists; see [data sources](/data/).
