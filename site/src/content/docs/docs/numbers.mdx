## Reference

### analyzeNumber()

```ts
function analyzeNumber(phone: string): NumberInfo | null;

type NumberType =
  'mobile' | 'landline' | 'uan' | 'toll-free' | 'premium' | 'personal'; // 'personal' is never returned since 2.7.0

interface NumberInfo {
  type: NumberType;
  formatted: string; // national format, e.g. 021-111-825-888
  e164: string | null; // e.g. +9221111825888
  areaCode: string | null; // e.g. 021, for landlines and UANs
  cities: string[]; // cities served by the area code, when known
}
```

**Parameters.** `phone`: a number in local or international format.

**Returns** the number details, or `null` if it is not a valid Pakistani number. `formatted` is the national format with the trunk prefix and separators.

**Caveats.**

- `e164` is `null` for a UAN dialled without an area code (`111-123-456`).
- `cities` is filled only when the area code is known.
- Service numbers follow PTA's numbering plan (sent to the ITU on 9 November 2021): a UAN is an area code, `111` and six digits; a toll-free number is `0800` and five digits there, or six in PTA's National Numbering Plan 2008 (sections 8.1 and 8.1.4; in use, such as Soneri Bank's `0800005000`), and both are accepted since 2.7.1. Premium-rate numbers are `0900` and five digits, the "current structure" in PTA's National Numbering Plan 2008, as the 2021 plan does not list 0900. Before 2.7.0 an 8-digit toll-free form was also accepted; no PTA document has it.
- Fixed-line patterns come from Google libphonenumber's PK metadata (v9.0.41), which matches the plan. `0122` numbers are seen in use but no PTA document lists them, so since 2.7.0 they are not recognised (`null`); libphonenumber calls them personal numbers.

**Related:** [`getNumberType()`](#getnumbertype), [`analyzePhone()`](/docs/phone/#analyzephone) for mobile numbers only.

### validateLandline()

```ts
function validateLandline(
  phone: string,
  options?: { services?: boolean },
): boolean;
```

**Parameters.** `phone`: a number in local or international format, such as `042-35761234`. `options.services`: also accept the service numbers a business may give as its landline: UAN (`021-111-123-456` or `111-123-456`), toll-free (`0800-12345`, `0800-005000`) and premium rate (`0900-12345`). Default `false`.

**Returns** `true` for a valid landline (fixed-line) number, or with `services`, a UAN, toll-free or premium number too. Mobile numbers and `0122` numbers return `false`. Use [`analyzeNumber()`](#analyzenumber) for the `type`. It never throws.

**Caveats.** The form adapters take the same option: `pk.landline({ services: true })`, `IsPakLandline({ services: true })`, `[PakLandline(Services = true)]` in .NET and `pk_landline:services` in Laravel.

**Related:** [`validatePhone()`](/docs/phone/#validatephone) for mobile numbers.

### getAreaCode()

```ts
function getAreaCode(city: string): string | null;
```

**Parameters.** `city`: a city name, case-insensitive.

**Returns** the landline area code with the trunk prefix (for example `"042"`), or `null` if the city is not in the dataset.

**Data.** 114 area codes, from the numbering plan PTA sent to the ITU in November 2021, which lists every code with its district. Names are spelt as the districts in the library's district list.

**Related:** [`analyzeNumber()`](#analyzenumber).
