## Reference

### validatePhone()

```ts
function validatePhone(phone: string): boolean;
```

**Parameters.** `phone`: a mobile number in any of the forms above.

**Returns** `true` for a mobile number with an allocated `03XX` prefix. Landlines, UAN and toll-free numbers return `false` (see `analyzeNumber()` for those).

**Related:** [`formatPhone()`](#formatphone), [`analyzePhone()`](#analyzephone).

### formatPhone()

```ts
function formatPhone(phone: string): string | null;
```

**Returns** the number in E.164 form (`+923001234567`), or `null` when it is not a valid mobile number.

### analyzePhone()

```ts
function analyzePhone(phone: string): PhoneAnalysis;

interface PhoneAnalysis {
  valid: boolean;
  formatted: string | null; // E.164
  network: string; // 'Jazz' | 'Zong' | 'Ufone' | 'Telenor' | 'SCO' | 'Unknown'
}
```

**Returns** validity, the E.164 form and the original network in one call.

### getNetwork()

```ts
function getNetwork(phone: string): string;
```

**Returns** `Jazz`, `Zong`, `Ufone`, `Telenor`, `SCO` (0355, Azad Jammu and Kashmir and Gilgit-Baltistan) or `Unknown`.

**Caveats.** This is the network the prefix was first allocated to. Pakistan has mobile number portability, so a number may have moved to another operator since.

**Related:** [`createWhatsAppLink()`](/api/typescript/whatsapp/functions/createwhatsapplink/), [`phoneRiskSignals()`](/api/typescript/quality/functions/phonerisksignals/).
