## Reference

### getDistrictPopulation()

```ts
function getDistrictPopulation(district: string): DistrictPopulation | null;
// { district, province, population, households, urban, rural, census: 2023,
//   censusDistrict, boundaryChanged, note, source }
```

**Returns** the census figures for any of the 177 districts.

**Caveats.**

- **Districts created after the census** have `null` figures and name the census district their area came from. Nothing is estimated.
- **Districts that lost area** keep their census-boundary figures, with `boundaryChanged: true`.
- **Gilgit-Baltistan and Azad Jammu and Kashmir** were not enumerated, so their figures are `null`.

### getTehsilPopulation()

```ts
function getTehsilPopulation(
  tehsil: string,
  district?: string,
): TehsilPopulation | null;
```

**Returns** the figures for one of the census's 591 tehsils, talukas and sub-divisions. A few names occur in two districts; pass the district to choose.
