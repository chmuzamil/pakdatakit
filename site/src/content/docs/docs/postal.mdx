## Reference

### getPostalCode()

```ts
function getPostalCode(city: string): string | null;
```

**Returns** the primary postal code of a city (case-insensitive), or `null` for an unknown city.

### getCityByPostalCode()

```ts
function getCityByPostalCode(postalCode: string): string | null;
```

**Returns** the city for one of its own post offices. A village code returns `null`; use `getPostOffice()` for those.

### getPostOffice()

```ts
function getPostOffice(code: string): PostOffice | null;

interface PostOffice {
  code: string;
  office: string;
  town: string;
  district: string | null;
  province: string;
}
```

**Returns** any delivery post office by its five-digit code.

**Caveats.** The directory is a separate data file, loaded only when these functions are first called.
