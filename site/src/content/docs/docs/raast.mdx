## Reference

### createRaastP2PQr()

```ts
function createRaastP2PQr(options: {
  iban: string;
  amount?: number;
  expiresAt?: Date;
  expiresIn?: string | number; // e.g. '1d', '2h', or milliseconds
  bankName?: string;
  particulars?: string;
}): string;
```

**Returns** the QR payload text.

**Caveats.** Person-to-person QR codes use scheme `00`: banking apps reject the `30` in SBP's document. A QR with an amount needs `expiresAt` or `expiresIn`. Test-scan with your bank's app before using a QR for payments.

### parseRaastQr()

```ts
function parseRaastQr(payload: string): ParsedRaastQr | null;
```

**Returns** the decoded fields (IBAN, bank, amount, expiry), or `null` when the text is not a Raast QR.

### validateRaastQr()

```ts
function validateRaastQr(payload: string, now?: Date): RaastQrValidation;
```

**Returns** whether a scanned QR is safe to pay: the CRC, IBAN checksum, amount and expiry, with readable problems.
