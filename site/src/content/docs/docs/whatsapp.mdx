## Reference

### createWhatsAppLink()

```ts
function createWhatsAppLink(phone: string, message?: string): string | null;
```

**Parameters.**

- `phone`: a Pakistani mobile number in any supported format.
- `message`: optional pre-filled message. It is URL-encoded for you.

**Returns** a `https://wa.me/…` link, or `null` if the phone number is invalid. Without a message (or with an empty one) the link has no `?text=` part.

**Related:** [`validatePhone()`](/docs/phone/#validatephone), [`getNetwork()`](/docs/networks/#getnetwork).
