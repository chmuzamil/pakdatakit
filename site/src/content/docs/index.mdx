## Packages

| Package | Registry | Install |
| --- | --- | --- |
| [`pakdatakit`](/install/typescript/) | npm | `npm install pakdatakit` |
| [`pakdatakit`](/install/python/) (Python) | PyPI | `pip install pakdatakit` |
| [`pakdatakit`](/install/dart/) (Dart) | pub.dev | `dart pub add pakdatakit` |
| [`pakdatakit_flutter`](/install/flutter/) | pub.dev | `flutter pub add pakdatakit_flutter` |
| [`PakDataKit`](/install/dotnet/) (.NET), plus DataAnnotations and FluentValidation | NuGet | `dotnet add package PakDataKit` |
| [`chmuzamil/pakdatakit`](/install/php/) (PHP/Laravel) | Packagist | `composer require chmuzamil/pakdatakit` |
| [`pakdatakit-react`](/install/react/) | npm | `npm install pakdatakit-react` |
| [`pakdatakit-vue`](/install/vue/) | npm | `npm install pakdatakit-vue` |
| [`pakdatakit-angular`](/install/angular/) | npm | `npm install pakdatakit-angular` |
| `pakdatakit-faker` (seeded mock data) | npm | `npm install -D pakdatakit-faker` |
| `pakdatakit-pay` (JazzCash secure hash) | npm | `npm install pakdatakit-pay` |
